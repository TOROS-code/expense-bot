# Бот учёта расходов

Telegram-бот, который записывает траты и считает статистику по категориям.

## Что умеет

- записывать расход одной строкой: `кофе 250`
- считать траты за день, неделю и месяц с разбивкой по категориям
- показывать последние 10 записей
- выгружать все расходы в CSV (открывается в Excel)

## Стек

- Python 3.12+
- aiogram 3 (асинхронный Telegram API)
- SQLite через aiosqlite
- pytest (тесты слоя работы с базой)

Суммы хранятся в копейках целыми числами, чтобы не терять точность на float.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Дальше получить токен у [@BotFather](https://t.me/BotFather), вписать его в `.env`
вместо заглушки и запустить:

```bash
python bot.py
```

## Тесты

```bash
pytest -q
```

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | инструкция |
| `кофе 250` или `/add кофе 250` | записать расход |
| `/stats`, `/stats неделя`, `/stats месяц` | статистика по категориям |
| `/last` | последние 10 записей |
| `/export` | CSV-файл со всеми расходами |

## Структура

```
bot.py          хендлеры, парсинг сообщений
db.py           SQLite: вставка, статистика, CSV
tests/test_db.py тесты базы
```
